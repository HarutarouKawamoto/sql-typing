# 要求内容

## 概要

中級の章（12問＋ターニングポイント）を足す。集計（COUNT・SUM・MAX・AVG・GROUP BY・HAVING）、JOIN（INNER・LEFT）、サブクエリ、CASE、書き換え（INSERT・UPDATE・DELETE）を扱い、ターニングポイントは「社長に出す月次レポート」（顧客・注文・明細をつないで集計）。UPDATE の問題では「WHERE を付け忘れて全商品が0円になった事件」を会話で体験させる。

## 背景

- 壁打ちの決定8（中級の範囲・ターニングポイント）、決定16（中級の章）。PRD「中級の章」（P1）
- 本人の「上級まで作って」（2026-11-12）。中級の初期データ・GROUP BY と JOIN のステップ再生はできている

## 実装対象の機能

1. `data/chapters.yaml` に中級の章（level 2、初期データ `intermediate.sql`、テーブル4つ、新しいテーブル3つ）
2. 問題YAML 13個（`data/problems/intermediate/`）
3. `data/keywords.yaml` に中級の用語（level 2）
4. E2E：初級のターニングポイントをモード3・4でクリアすると中級が開く、中級の問題を遊べる（書き換えの問題をモード4でクリア）、中級のDBの地図に4つのテーブルと線

## 受け入れ条件

- [ ] `npm run validate:data` が通る（正解が動く・間違いの選択肢で結果が変わる・並びが1つに決まる・ステップ再生が作れる・句の途中まで実行できる）
- [ ] 一覧に中級の13問が出る。初級のターニングポイントをモード3・4でクリアすると中級の1問目が開く（E2E）
- [ ] UPDATE の問題をモード4で解ける（E2E）
- [ ] 中級の問題のDBの地図に、4つのテーブルと3本の線が出る（E2E）
