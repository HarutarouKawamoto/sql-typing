# 要求内容

## 概要

画面上のSQLのキーワードにカーソルを当てると（スマホではタップ）、英語の意味とSQLでの意味が出るようにする（`KeywordTip`）。あわせて、全キーワードを一覧で見られる用語辞典の画面（`DictionaryScreen`）を作る。

## 背景

- PRD 機能11（P0）。用語のデータ（`data/keywords.yaml`、16語）は問題を作るたびに足してきたが、見る画面がない
- PRD 機能13：スマホでも用語辞典は見られる
- 本人の「上級まで作って」（2026-11-12）の2つ目の機能

## 実装対象の機能

### 1. キーワードの場所（`src/core/keyword-spans.js`）
- `findKeywordSpans(sql, words)`：SQLの中の用語辞典の語の場所（文字の範囲と語）。文字列・コメントの中は見ない。大文字・小文字は区別しない
- 複数語の用語（`ORDER BY`・`IS NULL`・`IS NOT NULL`）は、空白だけをはさんで並んでいれば1つにまとめる（長いものを先に）

### 2. 用語辞典の中身（`src/core/dictionary.js`）
- `buildDictionary(keywords, problems)`：レベルごと（初級・中級・上級）に用語を並べ、それぞれに「初めて出てくる問題」（出題順で最初に `keywords` に入っている問題）を付ける。どの問題にも出てこない語は `null`

### 3. 説明を出す（`KeywordTipLayer`）
- `data-keyword` の付いた場所にカーソルを当てると、その近くに説明（語・英語の意味・SQLでの意味・例）を出す。離れたら消す
- 押す（タップ）と出す・もう一度押すと消す（スマホのため）
- キーを押したら消す（タイピング中に出たままにしない）。スクロールしたら消す
- 説明は1つだけ。`role="tooltip"`

### 4. 説明を出す場所
- モード1・2の打つSQL（`TypingArea`）。モード2のまだ埋まっていない空欄には出さない（箱で隠しているので、そもそも語がない）
- ステップ再生のSQL（`StepPlayer`）
- ヒント③の骨組み（`HintPanel`）
- 用語辞典の例
- モード3・4の入力欄（`textarea`）には出さない（入力欄の中の文字に印を付けられない）

### 5. 用語辞典の画面（`DictionaryScreen`）
- 一覧の「用語辞典」から開く。Esc か「一覧へもどる」で一覧へ。幅の狭い画面でも見られる
- レベルごとの見出し、各語に英語の意味・SQLでの意味・例（`code`）・初めて出てくる問題
- 初めて出てくる問題が開いていれば、押すとその問題のモード選択へ。開いていなければ題名と「まだ開いていません」。どの問題にも出てこなければ「問題にはまだ出てきません」

## 受け入れ条件

- [ ] モード1で WHERE にカーソルを当てると説明が出て、キーを押すと消える（E2E）
- [ ] ステップ再生のSQLでも説明が出る（E2E）
- [ ] 一覧から用語辞典を開くと16語が並び、SELECT の「初めて出てくる問題」を押すと1問目のモード選択になる（E2E）
- [ ] 幅375pxでも用語辞典を見られ、例のキーワードをタップすると説明が出る（E2E）
- [ ] キーワードの場所・初めて出てくる問題の決め方（単体テスト）

## スコープ外

- モード3・4の入力欄の中の説明
- 用語辞典の検索
- 苦手の記録（Scoring）の複数語の数え方を、3語（`IS NOT NULL`）に広げること
