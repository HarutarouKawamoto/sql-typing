# 要求内容

## 概要

モード3・4で実行したとき、判定の前に、書いた順に並んだ句のチップが実行順に入れ替わるアニメーション（見える化B、`ReorderIntro`）を流す。あわせて、一覧から開ける設定画面（`SettingsScreen`）を作り、見える化Bの on/off・ステップ再生の速さ・学習記録を消すことができるようにする。

## 背景

- 壁打ちの作る順番の最後「上級の見える化」のうち、見える化A（ステップ再生）と C（打ちながら変化）はできている。B（実行順の並び替え）がまだ（機能設計書のユースケース2に「見える化Bは、まだ流れない（別の作業）」と書いてある）
- PRD 機能8 の B は「設定で止められる」。PRD 機能12 は「設定画面から学習記録をすべて消せる（確認を1回はさむ）」
- 学習記録の形（`progress-schema.js`）には `settings.reorderAnimation`・`settings.replaySpeed` の枠がもうある。`replaySpeed` はステップ再生に渡しているが、変える画面がない

## 実装対象の機能

### 1. 句のチップ（`src/core/reorder.js`）
- `buildReorderChips(sql)`：SQLを句に分け（ClauseSplitter）、句ごとのチップ（句の種類・短くした句の文字・書いた順・実行順）を書いた順に返す
- 句に分けられないSQL・句が1つだけのSQL（入れ替わりがない）は `null`（アニメーションを流さない）
- チップの文字は、空白・改行を1つの空白にまとめ、長い句は途中で切って「…」を付ける

### 2. 見える化B（`ReorderIntro`）
- モード3・4で実行したとき、設定が on なら、判定の結果の場所にチップを書いた順に並べ、少し待って実行順に入れ替える（Motion の layout）。全体で1.5秒
- 判定は同時に始める。アニメーションが終わるまで判定の結果・結果の表は出さない（「判定しています…」の代わり）
- アニメーションの間は次の実行を受けない
- 時計はこれまでどおり実行を押したときで止まる（アニメーションの時間は数えない）
- OS の「動きを減らす」設定では流さない。設定が off でも流さない

### 3. 設定画面（`SettingsScreen`）
- 一覧の「設定」から開く。Esc か「一覧へもどる」で一覧へ
- 見える化B の on/off（チェックボックス）
- ステップ再生の速さ（0.5倍・1倍・2倍）
- 変えたらすぐ学習記録に保存する
- 「学習記録を消す」：押すと確かめ（「クリア状況・最高記録・苦手の記録を消します。元に戻せません」）を出し、「消す」で消す、「やめる」か Esc で閉じる。消したら知らせる
- 設定（見える化B・速さ）は消さない（学習の記録ではなく好みなので。本人の決定。2026-11-12）
- 壊れていて退避した古い記録（`sql-typing:progress:broken-…`）も消す（「すべて消せる」）

### 4. 学習記録（`src/data/progress-store.js`・`src/ui/state/progress.js`）
- `updateSettings(progress, patch)`：設定を変えた新しい記録を返す
- `clearProgress(storage, settings)`：記録と退避した古い記録を消し、設定だけ残した空の記録を保存して返す
- `useProgress` に `changeSettings`・`clearAll` を足す

### 5. 画面の切り替え（`navigation.js`）
- `{ screen: 'settings' }` と `openSettings`（一覧からだけ）

## 受け入れ条件

- [ ] モード3・4で実行すると、句のチップが書いた順 → 実行順に入れ替わり、そのあと判定の結果が出る（E2E）
- [ ] 設定で見える化B を off にすると、実行してもチップは出ず、すぐ判定の結果が出る（E2E）
- [ ] 句が1つだけのSQL・句に分けられないSQLでは流れない（単体テスト）
- [ ] 設定画面で速さを変えると学習記録に保存され、読み込み直しても残る（E2E）
- [ ] 「学習記録を消す」は確かめを1回はさむ。「やめる」では消えない。「消す」で星が消え、設定は残る（E2E・単体テスト）
- [ ] 一覧から設定画面へ行け、Esc で一覧へもどる（E2E）

## 成功指標

- PRD 機能8 の B と、機能12 の「設定画面から学習記録をすべて消せる」を満たす

- 用語辞典・DBの地図
