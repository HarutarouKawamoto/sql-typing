# 要求内容

## 概要

仮の入口（1問目のボタンが並ぶだけ）を、章と問題の一覧に置き換える。問題を選ぶとモードを選べ、依頼の会話（StoryPanel）を1行ずつ読んでから遊ぶ。クリアすると反応の会話が出て、次の問題か一覧へ進める。前の問題をクリアすると次の問題が開き、ターニングポイントはモード3・4でクリアしたときだけ次の章が開く。幅768px未満では遊べないことを知らせ、会話だけは読めるようにする。

## 背景

- 壁打ちの作る順番は「… → モード2〜4 → ストーリー → 上級の見える化」。4つのモードがそろった
- 今は仮の入口で、会話はモード3・4の画面に並べているだけ。依頼の会話を読んでから打つ流れ（PRD 機能3）、一覧と進む条件（機能2）、端末の切り替え（機能13）がない
- モード3・4の作業で「幅768px未満の知らせは一覧画面の作業で入口と一緒に作る」と残した

## 実装対象の機能

### 1. 進む条件（`src/data/progress-store.js`）
- `isUnlocked(progress, chapters, problemId, turningPointIds)`：最初の章の最初は常に開く。前の問題がターニングポイントならモード3・4、それ以外ならどれかのモードでクリア済みなら開く（実装の途中で、ターニングポイントを「章の最後の問題」ではなく問題の kind で決める形に変えた。作っている途中の章にはターニングポイントがないため）
- `nextProblemId(chapters, problemId)`：次の問題（章の終わりなら次の章の最初、なければ null）

### 2. 一覧（HomeScreen）
- 章ごとに問題を出題順に並べる。各問題に番号・題名・ターニングポイントの印・星4つ（モードごとのクリア）
- 開いていない問題は題名だけ見えて選べない
- データベースの準備の状態、学習記録が壊れていたときの知らせ

### 3. モードを選ぶ（ModeSelect）
- 問題の題名、4つのモードのボタン（星・最高記録）。1〜4のキーでも選べる。Esc で一覧へ
- データベースの準備ができるまで選べない
- 幅768px未満では選べず「PCで遊んでください」。依頼の会話は読める

### 4. 依頼の会話（StoryPanel）
- 話している人の名前（色つき）と1行ずつ。Enter かクリックで次の行、最後の行のあと遊ぶ画面へ。「スキップ」で飛ばす。Esc で一覧へ

### 5. クリア後の会話と次へ
- クリアの結果の下に反応の会話（1〜4行）と「次の問題へ（N）」「一覧へ（Esc）」。Enter は今までどおり「もう一度」（のちに本人の決定で、Enter・J で次の問題へ、R でもう一度に変えた）
- ターニングポイントをモード1・2でクリアしたときは、モード3・4でクリアすると次の章が開くことを添える
- 遊ぶ画面の Esc は一覧へ

## 受け入れ条件

- [ ] 一覧に章と問題、星4つが出る。開いていない問題は選べない
- [ ] 1問をどれかのモードでクリアすると次の問題が開く。ターニングポイントはモード3・4だけで次の章が開く（単体テスト）
- [ ] 問題を選ぶとモードを選べ（クリックか1〜4）、依頼の会話を Enter・クリックで送り、スキップでき、そのあと遊べる
- [ ] クリアすると反応の会話が出て、「次の問題へ」「一覧へ」に進める。Enter でもう一度は変わらない
- [ ] 一覧・モード選択で最高記録と星が見え、読み込み直しても残る
- [ ] 幅375pxでは遊べず「PCで遊んでください」が出て、会話は読める
- [ ] `npm run check` と `npm run test:e2e` が通る

## 成功指標

- 本人が一覧から1問目を選び、会話を読んでから4つのモードで遊べる
- 初級2〜9問目を足したとき、一覧に並び、順に開いていく

## スコープ外

- 初級2〜9問目とターニングポイントの問題データ（次の作業。今は1問だけなので、次の問題・次の章の画面での流れは単体テストで確かめる）
- 用語辞典・設定・DBの地図の画面（一覧からのリンクも作らない）
- 見える化B
