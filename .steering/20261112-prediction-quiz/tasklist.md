## 実装検証の指摘への対応

| 指摘 | 対応 |
|---|---|
| [高] docs・レビュー用の記録がない | 検証を流したあとに書いた（検証は実装の直後に流したため）。設計書の `PredictionResult` の置き場所も実装に合わせた |
| [中] 選択肢が「正解の隣」「正解の倍」の形で透ける | 直した。埋め方を「正解の半分・正解 + 半分・正解の近く」にし、足りるうちは段階の中で一番多い行の数を超える数を使わない（テストあり） |
| [中] 答えたあとフォーカスがページに落ち、モード1・2で Enter が「次の問題へ」になる | 直した。答えたら再生・一時停止のボタンへフォーカス（E2E：モード1でキーボードだけで答え、続けて Enter） |
| [中] クイズ中の R・J | 見送り。ステップ再生のあいだと同じく、はっきり押すキーなので効くままにした。機能設計書に書いた |
| [中] 答えた直後に自動再生が始まる | 見送り。仕様どおり。流れの文は再生の上に出したまま |
| [中] キー操作の E2E がない | 足した（モード1で Tab・Enter で答える、フォーカス、Enter で次の問題へ進まない） |
| [低] 読み上げの文に3桁ごとの区切りがない | 直した。画面と同じ文（`prediction-text.js`、単体テスト） |
| [低] 読み上げが画面の文の二重 | 見送り。ほかの見える化と同じ形（先に置いた枠に入れる） |
| [低] SQL が変わっても答えが残る | 呼ぶ側が key を変える前提を JSDoc に書いた（3つの呼ぶ側はすべて key を付けている） |
| [低] 答えないと「見た」記録が付かない | 仕様として機能設計書に書いた |
| [低] テストの抜け（設定の一部だけの古い記録・文の関数・大きい結果） | 足した |
| [低] CSS の `:focus-visible`・`.srOnly` の重なり | 見送り。ほかの部品と同じ形 |
