# 要求内容

## 概要

見える化D「実行前の予想クイズ」を作る。ステップ再生の前に「このSQLの結果は何行になる？」を4択で当ててから再生する。答えたら、当たり・はずれと、段階ごとの行の数の流れ（FROM 30行 → WHERE 21行 → …）を見せ、そのまま再生する。

## 背景

- PRD「実行前の予想クイズ（見える化D）」（P2）
- 本人の「次の機能を始めて、上級まで作って」で、見える化D も作ると決めた（2026-11-12）。この作業で頼まれた範囲は最後
- ブランチ名は、ブランチを決めるダイアログで本人が選んだ `claude/changes`（前の同じ名前のブランチはマージ済み。`main` の位置から作り直した）

## 実装対象の機能

### 1. 選択肢を作る（`src/core/prediction.js`）
- `buildRowCountQuiz(steps)`：正解（最後の段階の行の数）、4つの選択肢（小さい順）、段階ごとの行の数の流れ
- 紛らわしい選択肢は、途中の段階の行の数を先に使う（「WHERE を忘れると全部の行」などのよくある考え違い）。足りなければ正解の近くの数で埋める。乱数は使わない（同じ SQL ならいつも同じ）

### 2. 画面（`PredictionQuiz`）
- ステップ再生の段階ができたら、再生の前にクイズを出す。選択肢のボタン（4つ）と「予想しないで再生する」
- 答えたら：「当たり！」か「おしい！」、正解と自分の予想、段階ごとの行の数の流れ。そのままステップ再生が始まる
- 読み上げ：結果の文を `role="status"` で。クイズが出たら最初の選択肢にフォーカス

### 3. 設定
- 設定の画面の「見える化」に「ステップ再生の前に、結果の行の数を予想するクイズを出す（見える化D）」。既定は on。学習記録の設定に `predictionQuiz`（古い記録は既定で on）
- モード1〜4のステップ再生で、設定が on なら出す
- 見本のページ（`/?demo`）は `&predict` のときだけ出す（今の見本の E2E を変えないため）

## 受け入れ条件

- [ ] 選択肢：正解を含む4つ、重ならない、小さい順、途中の段階の行の数が入る、0行の結果でも作れる（単体テスト）
- [ ] 当てると「当たり！」、外すと「おしい！」と正解。どちらもそのあと再生が始まる（E2E）
- [ ] 設定で off にすると出ない（E2E）

## スコープ外
- 「どの行が残る？」（行を選ぶ画面が要る。後の作業）
- 予想の当たり・はずれを学習記録に残すこと
