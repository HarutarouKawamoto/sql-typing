## なぜ

- **線の太さは対数**：5万行と1行をそのまま比べると、1行の線が見えないか、5万行の線が箱より太くなる
- **葉が下・根が上**：PostgreSQL の EXPLAIN の字下げ（根が上）と同じ向きで、下から上へ行が流れる
- **実行されなかった節は点線の箱、文字は薄くしない**：色の薄さだけに頼ると読めない（実装検証の指摘）
- **副問い合わせは点線の線**：行が流れるのではなく、上の節が行ごとに呼ぶ。同じ線だと「上へ0行流れた」と読めてしまう
- **`fitText` で縮める**：SVG の文字は折り返さない。索引名つきの節が上級の主役になるので、はみ出しを止めた
